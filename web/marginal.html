MATLAB 代码如何在浏览器运行

本页加载 RunMat WebAssembly 运行器，读取并执行 Marginal_FullCollapsed_browser.m。数据生成、分组更新、alpha 抽样和均值计算都在 MATLAB 代码中完成。没有转换成 Python，也没有使用 JavaScript 重写的 MCMC 算法计算结果。

JavaScript 负责输入检查、启动后台 Worker、接收迭代进度和绘图。GitHub Pages 只托管网页、源码与运行器，计算使用你的设备。完成后再次运行可复用已加载的运行器；停止会终止后台任务。

适配版保留原分组概率和 alpha 更新公式，维护各组人数与总和以减少重复扫描。运行器缺少的单次多项抽样改用均匀随机数，Beta 抽样使用两个独立 Gamma 样本的比值，均写在 .m 中。少量数组操作使用兼容写法。

参考线在正数范围求解原方程，避免原 fzero 初值在小样本时落入负值奇点。随机数发生器与 MATLAB 不同，随机样本不保证逐项相同。RunMat 是第三方 MATLAB 语法运行器，不等于完整 MathWorks MATLAB。
