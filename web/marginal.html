不是转换成 Python：本页如何计算

本程序的数值部分已人工等价移植为 JavaScript，在浏览器的 Web Worker 中运行。GitHub Pages 只发送网页和代码；用户的设备负责生成数据、MCMC 迭代与绘图。

每次迭代先逐个重新分配样本，再更新 alpha。网页维护各组人数与数值总和，避免原程序中重复扫描全部样本。分组概率、alpha 更新公式和最终均值抽样沿用原程序。

原程序的单次多项分布选择用均匀随机数实现；Beta 抽样使用两个独立 Gamma 样本的比值；参考线用二分法在正数范围求解同一个方程，避免原 fzero 初值在小样本时落入负值奇点。随机数发生器与 MATLAB 不同，所以两次运行、或与 MATLAB 的随机结果不要求逐项相同。

热扩散和正态随机数页面仍由 RunMat 的 WebAssembly 运行器执行 .m。这一页使用轻量的 JavaScript 计算文件，无需下载该运行器。
